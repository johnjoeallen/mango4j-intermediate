# mango4j-spring-logging

## Overview

Mango4j Spring logging is a structured logging framework for building robust logging for your Spring Boot applications.

Mango4j Spring logging is compatible with the Mastercard APPF logging libraries, and includes them as a dependency.

## How to use?

### Add the dependency
In order to make use of the library, you need to import the following dependency into your project.

#### Gradle Dependency

```groovy language=groovy
implementation("com.mastercard.commons.mango:mango4j-spring-logging:1.0.0")
```

#### Maven Dependency

```xml language=xml
<dependency>
    <groupId>com.mastercard.commons.mango</groupId>
    <artifactId>mango4j-spring-logging</artifactId>
    <version>1.0.0</version>
</dependency>
```

Happy coding!
