# mango4j-intermediate

Staging repo for the Spring Boot 4 / Java 25 consolidation of the mango4j family. Each group is a
parent-pom directory plus its modules and will be pushed to its own GitHub repo.

See [MIGRATION.md](MIGRATION.md) for layout, dependency analysis and status.

```bash
mvn clean verify -Dgpg.skip     # build everything
```
